# Fase 3 — Contrato de auditoria do onboarding

Antes de alterar o onboarding, verificar:

- quais passos já existem;
- quais campos são obrigatórios e opcionais;
- se o usuário consegue voltar;
- se o progresso sobrevive ao fechamento;
- se é possível refazer sem apagar registros;
- qual é a primeira meta criada;
- qual é a primeira ação orientada depois da configuração;
- em quais situações o onboarding bloqueia o uso.

Requisitos do plano:

- fluxo completo;
- salvar progresso;
- permitir voltar;
- permitir pular campos opcionais;
- refazer sem apagar registros;
- criar a primeira meta;
- orientar a primeira ação;
- não bloquear o uso indevidamente;
- validar com usuário real.

Nenhuma mudança de comportamento deve ser aplicada sem um teste que caracterize o estado atual ou o requisito correspondente.
